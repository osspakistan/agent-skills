# Tokenheimer visual system

Read this only when maintaining `assets/report-template.html`. Normal report runs should use the template as-is.

The template is based on Kami's editorial design system: https://github.com/tw93/Kami/tree/main/skills/kami

Preserve these invariants:

- parchment-first light surface (`#f5f4ed`) with warm ivory/sand neutrals;
- ink blue (`#1B365D`) as the restrained accent;
- deep warm dark mode rather than neon/glass dashboard styling;
- serif-led editorial hierarchy with compact sans-serif UI labels;
- approximately 1120px maximum reading/report width;
- spacing, rules, typography, and tables provide hierarchy before cards or shadows;
- flat, quiet controls and minimal decoration;
- automatic, light, and dark themes;
- responsive report composition, especially session metrics; never restore a narrow right-side metric rail.

Do not replace this with a generic analytics dashboard, colorful KPI-card grid, gradient UI, glassmorphism, or another design language unless the user explicitly asks for a redesign.
