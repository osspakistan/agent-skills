# Prompt: Review / Comparison

Use for: product review articles, "best X" listicles, comparison articles, spec sheets written with opinion, product review videos, "should you buy" videos, hands-on test videos, comparison videos.

---

You're summarizing this for someone deciding whether to buy, use, or adopt something.

Focus: Does it work? What's good? What's bad? Who should buy it?

---

## Output Format

TITLE: [Product Name — Verdict / Improved Title]

**Opening (no header)**
One sentence verdict: Does the reviewer recommend it? (Yes / No / It depends).

## [*keep this section head dynamic. Keep it conversational and max 3 words. Use casual language. Examples: "What Works", "The Hits", "Highlights". Unlike standard headings, do NOT use the `The {xyz}` pattern*]

What works well. Be specific — name the exact feature, metric, speed, or use case:
- Feature with concrete detail
- Feature with concrete detail

## [*keep this section head dynamic. Keep it conversational and max 3 words. Use casual language. Examples: "Trade-offs", "Downsides", "What Fails". Unlike standard headings, do NOT use the `The {xyz}` pattern*]

What doesn't work or disappoints:
- Issue with specific detail
- Issue with specific detail

## [*keep this section head dynamic. Keep it conversational and max 3 words. Use casual language. Examples: "Who Buys", "Ideal Match", "Skip If". Unlike standard headings, do NOT use the `The {xyz}` pattern*]

Format for scanning — don't write generic paragraphs:
- **Buy if:** [concrete scenario/reason]
- **Skip if:** [concrete scenario/reason]
- Or use a comparison table if evaluating multiple competitors.

**vs. Competitors** *(skip if no comparison made)*
- *Product A*: one-line verdict
- *Product B*: one-line verdict

**Price** *(skip if not mentioned)*
Include price/availability if stated.

---

### Strict Heading & Quality Rules:
- Dynamic headers MUST be conversational, max 3 words, and NEVER use `The {xyz}`.
- Prioritize specs, benchmarks, prices, and hard facts over opinionated marketing adjectives.
- Tone: Honest about trade-offs. Help someone make an immediate buying decision.
